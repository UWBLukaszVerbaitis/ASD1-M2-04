    sprawdzone++ ; porównania++

    Sortowanie przez wstawianie (ranking)

    insertionSort(a, cmp):
  dla i = 1 … n−1:
    key = a[i] ; j = i−1
    dopóki j ≥ 0:
      porównania++
      jeśli cmp(a[j], key) > 0:     // a[j] ma być ZA key
        a[j+1] = a[j] ; j−−         // przesunięcie
      inaczej: przerwij
    a[j+1] = key                     // O(n) … O(n²)
cmp(a,b): głosy malejąco, potem ID rosnąco
